# BinAsor — Luxury Fashion & Apparel Storefront

A modern, responsive e-commerce web application for luxury clothing, footwear, and designer accessories. Built with React (JSX) and Vanilla CSS, featuring full catalog filtering, interactive cart drawer, wishlist curation, and an administrative management dashboard.

## Features

- **Modern Editorial Design**: Minimalist luxury aesthetics featuring serif typography and smooth micro-interactions.
- **Dynamic Catalog & Filtering**: Filter apparel by category, price ceilings, stock status, and promotional badges.
- **Shopping Bag & Drawers**: Real-time quantity management, coupon code discounts, and free worldwide shipping milestone tracking.
- **Atelier Concierge**: Interactive customer inquiry portal with direct messaging feedback.
- **Admin Dashboard**: Comprehensive management console for inventory CRUD, order tracking, and category taxonomy.
- **Modular Components**: Handcrafted, self-coded reusable UI components (`Button`, `Badge`, `RatingStars`, `QuantitySelector`, `EmptyState`, `Breadcrumb`).

## Tech Stack

- **Frontend**: React 19, JavaScript (JSX)
- **Styling**: Modular Vanilla CSS with per-page stylesheets
- **Icons**: Lucide React
- **Build Tool**: Vite

## Getting Started

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Start Development Server:**
   ```bash
   npm run dev
   ```

3. **Build for Production:**
   ```bash
   npm run build
   ```

## Admin Access
